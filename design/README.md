# Systems & interfaces

This profile uses original vector artwork: a geometric COJOVI wordmark, an orbital wireframe sculpture, technical borders, and individual project illustrations. CMAC's feature contains an actual screenshot of its public showroom.

The visual language combines midnight blue, ice cyan, muted violet, and project-specific accents. The layout uses native Markdown and links alongside the artwork so the work remains easy to navigate and read.

## Assets

- `assets/hero.svg` is the animated desktop composition. The `-mobile` versions recompose the layout for narrow screens; the `-still` versions remove animation.
- The README uses `picture` sources for narrow screens and reduced-motion preferences. Animated SVGs also include their own reduced-motion rules.
- Project artwork illustrates each build; the feature screenshot shows the real CMAC interface.
- All artwork is stored in the repository. There are no third-party statistics cards, tracking pixels, or generated activity claims.
- SVGs are editable source files. Visible text has corresponding native copy or descriptive alternative text in the README.

## Typography

Space Grotesk and JetBrains Mono are distributed under the SIL Open Font License. The font sources and license notices are in [fonts](fonts/). The SVG files contain embedded font subsets. The COJOVI wordmark uses original geometric paths.

Font sources: [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono).
